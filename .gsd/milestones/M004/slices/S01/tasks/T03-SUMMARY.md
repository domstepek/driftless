# T03: Deploy to Vercel and verify cross-links

**Deployed apps/web to Vercel as production at `driftless-six.vercel.app` with full landing page, docs, cross-links, OG meta tags, and 268 tests passing.**

## What Happened

First deploy attempt from `apps/web` directory failed — Vercel defaulted to `npm install` and couldn't resolve pnpm workspace dependencies. Second attempt from monorepo root auto-detected "No framework" since root is a plain monorepo, not a Next.js app. Build succeeded but deployment errored because Vercel didn't know how to serve the output.

Fixed by configuring the Vercel project via API: set `rootDirectory: apps/web`, `framework: nextjs`, `installCommand: pnpm install`, `buildCommand: next build`. Third deploy succeeded — Vercel correctly ran `pnpm install` from root (detecting pnpm-lock.yaml), then `next build` from `apps/web`.

Production URLs:
- `https://driftless-six.vercel.app` (alias)
- `https://driftless-cmvtaez9u-domstepeks-projects.vercel.app` (deployment)

Also connected to GitHub repo `domstepek/driftless` during deploy.
